Technical Assessment — Web Developer

Data Collection Approach

This listing page simulates what an automated data collection pipeline would produce for the Bali Home Immo CMS. Rather than manually copy-pasting property details, a web developer would build:

  • A parser script (Python/Node.js) to extract structured fields from listing sources
  • A data cleaning layer to normalize prices, specs, and location strings
  • A JSON formatter outputting records directly insertable into the database
  • A CDN pipeline to compress and host property images in .webp format

Database Schema (JSON)

Each property maps to a consistent schema for the backend CMS. This ensures frontend rendering components can rely on stable data shapes:

  • property_id — unique slug (e.g. BHI-TABANAN-001)
  • price — IDR + optional USD, Freehold/Leasehold type
  • specs — beds, baths, pool, land_m2, build_m2
  • media — CDN URL array in .webp format for fast page load
  • legality — SHM/SHB/Leasehold with duration & renewal flag
