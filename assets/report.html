1. INTRODUCTION & TECHNICAL APPROACH

This report is submitted as part of the Web Developer recruitment selection at Bali Home Immo. In response to the property listing simulation task, I approached this challenge through a full-stack developer lens, combining automated data aggregation with an interactive frontend demonstration. The deliverables for this assessment include this PDF report documenting the data collection methodology, structured property listings, and backend JSON data mappings, as well as a fully functional, responsive HTML demo page built with vanilla HTML, CSS, and JavaScript.

The demo page features image sliders, property cards, and inline JSON code blocks that mirror the Bali Home Immo visual identity. Rather than relying on manual copy-pasting, the property data presented here is simulated as the output of an automated parsing pipeline using Python or Node.js, which extracts raw listings from public marketplace channels, normalizes the fields, and outputs database-ready JSON objects ready for direct CMS ingestion.
